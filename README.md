# Majority

Пртототип механики поиска сокровищ на UE 5.2 c++
При активации режима поиска сокровищ появляется металлодетектор. Выбирается случайное сокровище на карте. Чем ближе персонаж к сокровищу, тем чаще мигает маячок.
Когда сокровище раскопано, оно добавляется в инвентарь.
